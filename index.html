Hallazgos del análisis

Hallazgo 1. Concentración de esterilizaciones por municipio

El análisis de los registros evidencia que las esterilizaciones no se distribuyen de manera uniforme entre los municipios del Valle del Cauca. Yumbo registra la mayor cantidad de intervenciones reportadas, con 48 registros, destacándose como el municipio con mayor participación dentro del conjunto de datos analizado.

Verificación: Se realizó un conteo de registros agrupados por municipio y se representaron los resultados mediante una gráfica de barras.

Hallazgo 2. Distribución por especie

La comparación entre felinos y caninos permite identificar diferencias en la cantidad de procedimientos realizados para cada especie. Durante el análisis también se detectó una inconsistencia en la variable "Tipo de Animal", debido a la existencia simultánea de las categorías "Canino" y "Caninos", situación que requiere procesos de depuración para evitar resultados duplicados.

Verificación: Se revisaron y agruparon las categorías registradas en la variable "Tipo de Animal" y se visualizaron mediante un gráfico circular.

Hallazgo 3. Distribución según sexo

Los datos muestran una distribución equilibrada entre hembras y machos, registrándose 192 procedimientos para cada grupo. Este comportamiento sugiere una cobertura homogénea de las intervenciones dentro del conjunto de datos analizado.

Verificación: Se agruparon los registros por la variable "Sexo" y se calcularon sus frecuencias para su representación gráfica.

Hallazgo 4. Importancia de la calidad de los datos

Durante la exploración del conjunto de datos se identificaron diferencias en la forma de registrar algunas categorías. Esto demuestra la importancia de realizar procesos de validación y limpieza de datos antes de efectuar análisis definitivos y generar conclusiones confiables.

Verificación: Revisión manual de registros y comparación de categorías similares con diferentes formas de escritura.
