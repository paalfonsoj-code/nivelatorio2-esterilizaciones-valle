# Validación crítica

## Error 1

La IA generó un archivo HTML que se visualizaba como texto plano en el navegador.

### Cómo se detectó

Al abrir index.html todo el contenido aparecía en una sola línea.

### Corrección

Se revisó la estructura HTML y se corrigieron errores de sintaxis.


## Error 2

La IA propuso valores ficticios para los gráficos.

### Cómo se detectó

Los valores no provenían del archivo esterilizaciones.csv.

### Corrección

Se decidió reemplazar los datos de ejemplo por resultados calculados directamente desde el dataset.
