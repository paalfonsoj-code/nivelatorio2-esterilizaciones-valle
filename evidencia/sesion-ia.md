# Sesión de trabajo con IA

## Herramienta utilizada

Gemma ejecutado localmente mediante Ollama.

## Objetivo de la interacción

Obtener apoyo para la construcción de una página web que permitiera analizar el conjunto de datos sobre esterilizaciones de felinos y caninos en el Valle del Cauca.

## Prompt 1

Actúa como analista de datos y desarrollador web.

Estoy desarrollando una práctica académica utilizando el dataset "Esterilizaciones de Felinos y Caninos en el Valle del Cauca".

La pregunta de análisis es:

¿Cómo se distribuyen las esterilizaciones de felinos y caninos entre los diferentes municipios del Valle del Cauca y cuál es la proporción histórica entre especies e intervención por género?

Genera una propuesta de estructura para una página web con introducción, objetivo, gráficos y hallazgos.

## Resultado obtenido

La IA propuso:

- Estructura HTML.
- Diseño inicial en CSS.
- Gráficos sugeridos con Chart.js.
- Organización del contenido.
- Sección para documentar el uso de IA.

## Ajustes realizados por el estudiante

- Se revisó la estructura del proyecto.
- Se corrigieron errores de visualización del archivo HTML.
- Se verificó la coherencia entre la pregunta de análisis y las visualizaciones propuestas.
- Se adaptó el contenido al conjunto de datos real descargado desde Datos Abiertos Colombia.

## Conclusión

La IA fue utilizada como herramienta de apoyo para acelerar el desarrollo del proyecto, pero todas las decisiones finales fueron verificadas y ajustadas manualmente.
