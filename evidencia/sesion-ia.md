# Sesión de trabajo con IA

## Herramienta utilizada

Gemma ejecutado localmente mediante Ollama.

## Objetivo de la interacción

Obtener apoyo para la construcción de una página web que permitiera analizar el conjunto de datos "Esterilizaciones de Felinos y Caninos en el Valle del Cauca", documentar el proyecto y generar visualizaciones que ayudaran a responder la pregunta de análisis.

---

## Prompt 1

Actúa como analista de datos y desarrollador web.

Estoy desarrollando una práctica académica utilizando el dataset "Esterilizaciones de Felinos y Caninos en el Valle del Cauca".

La pregunta de análisis es:

¿Cómo se distribuyen las esterilizaciones de felinos y caninos entre los diferentes municipios del Valle del Cauca y cuál es la proporción entre especies y sexo de los animales intervenidos?

Genera una propuesta de estructura para una página web con introducción, objetivo, gráficos y hallazgos.

### Resultado obtenido

La IA propuso:

- Estructura HTML.
- Estilos CSS.
- Organización del contenido.
- Inclusión de gráficos con Chart.js.
- Sección para documentar el uso de IA.

### Ajustes realizados por el estudiante

- Se adaptó la estructura al proyecto académico.
- Se ajustaron los títulos y secciones.
- Se verificó la coherencia con la pregunta de análisis.

---

## Prompt 2

Propón visualizaciones adecuadas para analizar la distribución de esterilizaciones por municipio, especie y sexo.

### Resultado obtenido

La IA sugirió:

- Gráfico de barras para municipios.
- Gráfico circular para especies.
- Gráfico circular para sexo.

### Ajustes realizados por el estudiante

- Se verificaron los datos utilizados.
- Se ajustaron las etiquetas y colores.
- Se corrigieron errores de visualización.

La IA fue utilizada como herramienta de apoyo para acelerar tareas de documentación, programación y organización del proyecto.
